# 药物推荐链路说明（输入输出版）

## 目标

将用户输入映射为药物候选列表，输出可解释分数，供 API 直接返回。

## API 入口

- 路由：`POST /v1/recommendation/drugs`
- 文件：`app/fastapi_module/router.py`
- 请求模型：`RecommendRequest`
- 响应模型：`RecommendResponse`

## 输入定义

- `symptom_text: str`
  - 用户自然语言症状描述（纯文本）。
- `diseases: list`
  - 每个元素是疾病标签及其置信度。
  - 支持两种格式：
    - `{"name": "common_cold", "confidence": 0.82}`
    - `{"common_cold": 0.82}`
- `symptoms: list`
  - 每个元素是症状标签及其置信度。
  - 支持两种格式：
    - `{"name": "fever", "confidence": 0.91}`
    - `{"fever": 0.91}`
- 可调参数
  - `top_k`
  - `recall_top_k_each`
  - `fused_top_k`
  - `recall_weight_semantic`
  - `recall_weight_label`

## 链路阶段与阶段输入输出

- 阶段 1：语义召回（MedBERT）
  - 输入：`symptom_text` + 全量药物向量矩阵
  - 输出：候选集 A，关键分数 `semantic_score`

- 阶段 2：标签召回（置信度加权）
  - 输入：`diseases/symptoms`（标签+置信度）+ 药物标签字段
  - 输出：候选集 B，关键分数 `label_score`、`disease_conf_overlap`、`symptom_conf_overlap`

- 阶段 3：双召回融合
  - 输入：候选集 A + 候选集 B + 召回权重
  - 输出：融合候选集，关键分数 `recall_fused_score`

- 阶段 4：Cross-Encoder 精排
  - 输入：融合候选集 + 重排 query（由 `symptom_text` 与标签拼接）
  - 输出：`cross_encoder_score`

- 阶段 5：业务打分
  - 输入：候选药物业务字段（`avg_rating`、`total_reviews`、可选 `price`）
  - 输出：`business_score`

- 阶段 6：最终分数
  - 输入：`recall_fused_score` + `cross_encoder_score` + `business_score`
  - 输出：`final_score`，按降序截断 `top_k`

## 输出定义

每个候选至少包含以下字段：

- `drug_name`
- `final_score`
- `recall_fused_score`
- `cross_encoder_score`
- `business_score`
- `semantic_score`
- `label_score`
- `disease_conf_overlap`
- `symptom_conf_overlap`
- `avg_rating`（可空）
- `total_reviews`（可空）
- `extra`（未列入标准字段的原始扩展字段）

## 离线资产依赖

- 结构化药物表：`match_data_preprocessing/data/enhanced_drug_table_v1_structured.csv`
- 药物向量矩阵：`drug_comprehensive_embeddings.npy`
- 生成脚本：`app/fastapi_module/offline_assets_builder.py`
