# 药物推荐链路实现说明（函数级别）

## 快速接入入口

- FastAPI app：`app.fastapi_module.app_main:app`
- 业务路由函数：`recommend_drugs()`
- 服务单例入口：`get_recommendation_service()`

## 模块职责拆分

- `app/fastapi_module/schemas.py`
  - `LabelWithConfidence`
  - `RecommendRequest`
  - `CandidateScore`
  - `RecommendResponse`

- `app/fastapi_module/router.py`
  - `health_check()`
  - `recommend_drugs()`

- `app/fastapi_module/service.py`
  - `_repo_root()`
  - `_default_drug_table_path()`
  - `_default_embedding_path()`
  - `DrugRecommendationService._build_components()`
  - `DrugRecommendationService.ensure_ready()`
  - `DrugRecommendationService.pipeline`
  - `DrugRecommendationService.recommend()`
  - `get_recommendation_service()`

- `app/fastapi_module/offline_assets_builder.py`
  - `build_assets()`
  - `parse_args()`

## 核心推荐实现（embedded_module）

- `app/embedded_module/dual_recall_pipeline.py`
  - 输入解析与标签处理
    - `parse_weighted_labels()`
    - `_build_confidence_map()`
    - `_build_rerank_query()`
  - 推荐主类
    - `DualRecallDrugRecommender.semantic_recall()`
    - `DualRecallDrugRecommender.label_recall()`
    - `DualRecallDrugRecommender.fuse_recalls()`
    - `DualRecallDrugRecommender.rerank()`
    - `DualRecallDrugRecommender.recommend()`
  - 公共辅助
    - `_min_max_normalize()`
    - `_to_float()`
    - `DualRecallDrugRecommender._business_score()`

- `app/embedded_module/cross_encoder_reranker.py`
  - `CrossEncoderReranker.__init__()`
  - `CrossEncoderReranker.score_pairs()`
  - `CrossEncoderReranker._convert_logits_to_scores()`

- `app/embedded_module/drug_embedding_engine.py`
  - `DrugEmbeddingEngine.encode()`
  - `DrugEmbeddingEngine.encode_query()`
  - `DrugEmbeddingEngine.save()`
  - `DrugEmbeddingEngine.load()`

- `app/embedded_module/recommendation_pipeline.py`
  - `prepare_drug_dataframe()`
  - `build_semantic_text()`
  - `normalize_symptom_name()`
  - `safe_cosine_scores()`
  - `build_query_text()`

## 一次请求的函数调用顺序

- `router.recommend_drugs()`
- `service.get_recommendation_service()`
- `DrugRecommendationService.recommend()`
- `DualRecallDrugRecommender.recommend()`
  - `semantic_recall()`
  - `label_recall()`
  - `fuse_recalls()`
  - `rerank()`
    - `CrossEncoderReranker.score_pairs()`
    - `_business_score()`
- `router.recommend_drugs()` 组装 `RecommendResponse`

## 配置点（环境变量）

- `DRUG_TABLE_PATH`
- `DRUG_EMBEDDING_PATH`
- `AUTO_BUILD_EMBEDDINGS`
- `MEDBERT_MODEL_NAME`
- `CROSS_ENCODER_MODEL_NAME`

## 后续 Agent 建议接入位点

- 修改请求协议：优先调整 `RecommendRequest`
- 修改融合权重策略：`DualRecallDrugRecommender.fuse_recalls()`
- 修改精排模型：`CrossEncoderReranker`
- 加安全规则（DDI/禁忌）：建议接入 `DualRecallDrugRecommender.rerank()` 之前或之后
- 加新业务特征：`DualRecallDrugRecommender._business_score()`
