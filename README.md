# Medical Chatbot for Diagnosis & Medication Recommendation

---

## Run the Program

```powershell
# go to the root folder
cd the/root/folder
# create virtual environment for the program
python -m venv .venv
# activate the environment 
.venv/Scripts/activate
# install the environment requirements
pip install -r requirements.txt
# run the program in cli model
python -m app
# or run the program in ui model
python -m app python -m app ui --server.port 8080 --server.address 0.0.0.0
```
